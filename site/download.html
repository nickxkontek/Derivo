Questions

How do I install it?

Download Derivo-Setup.exe, open it, and follow the steps. Derivo is added to the Start menu and the desktop, and .derivo files open in it. To remove it, use Settings → Apps.

Windows showed a "Windows protected your PC" message

Windows SmartScreen shows this for new apps it hasn't seen often yet. Click More info → Run anyway. The message goes away as more people install the app.

How do updates work?

Derivo checks for a new version when it starts, downloads it in the background, and installs it the next time you close the app. You can also check from Help → Check for updates.

Do I need internet?

No. Everything, including the math typesetting, runs on your computer. The internet is only used to check for updates.
